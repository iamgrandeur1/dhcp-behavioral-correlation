# DHCP Behavioral Correlation & Threat Hunting Using Splunk

This repository documents a behavioral DHCP analysis and threat hunting project using Splunk and Zeek logs.

The objective of this project was to correlate DHCP client behavior, validate baseline network activity, and investigate potential rogue DHCP indicators within a monitored environment.

---

##  Technologies Used

- Splunk
- Zeek
- Kali Linux
- VirtualBox

##  Focus Areas

- DHCP Analysis
- Behavioral Correlation
- SIEM Operations
